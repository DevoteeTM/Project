# Ссылки на трейлеры и просмотр фильмов в ТОП-20

## Для кого и зачем

Функция предназначена для пользователя, который просматривает ТОП-20 и хочет сразу найти официальный трейлер или перейти к легальному просмотру полного фильма. Ссылки формируются автоматически из названия и года фильма, поэтому для новой карточки ТОП-20 не требуется вручную указывать адреса.

## Что должно быть

- В каждой карточке раздела «Топ-20 фильмов» отображаются две отдельные ссылки: «Смотреть трейлер» и «Смотреть фильм».
- «Смотреть трейлер» открывает результаты поиска YouTube по названию фильма, году выпуска и словам «официальный трейлер».
- «Смотреть фильм» открывает поиск Кинопоиска по названию фильма и году выпуска. Кинопоиск используется как легальная платформа; фактическая доступность полного фильма, подписка и региональные ограничения определяются самим сервисом.
- Обе ссылки создаются программно при формировании карточки из полей `title` и `year`. Добавление нового объекта фильма в данные ТОП-20 автоматически даёт ему обе ссылки.
- Название и год передаются в адресе безопасно: пробелы, кириллица и специальные символы кодируются как параметры URL.
- Внешние страницы открываются в новой вкладке. Исходная страница со списком остаётся открытой.
- Ссылки имеют понятные подписи для экранного диктора с названием фильма и годом.
- Существующие постеры, места, названия, жанры, звёздные оценки, числовой рейтинг, прокрутка и навигация ТОП-20 сохраняются.
- Личная коллекция, её карточки, форма добавления, фильтры и данные `localStorage` не изменяются.

## Примеры

- Для фильма «Интерстеллар» 2014 года ссылка «Смотреть трейлер» открывает поиск YouTube по запросу «Интерстеллар 2014 официальный трейлер».
- Для фильма «Интерстеллар» 2014 года ссылка «Смотреть фильм» открывает поиск Кинопоиска по запросу «Интерстеллар 2014».
- Если в массив ТОП-20 добавить фильм «Дюна: Часть вторая» 2024 года, обе ссылки появляются в его карточке без ручного добавления URL.

## Ограничения

- Приложение не обращается к API YouTube, Кинопоиска или других сервисов и не загружает с них данные в фоне.
- Приложение не может гарантировать наличие фильма на платформе: каталог, подписка и доступность в Казахстане могут меняться.
- Переход на внешний сайт происходит только после явного нажатия пользователя.
- В приложении не сохраняются история переходов, учётные данные или ответы внешних сервисов.
- Используются только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Интерактивная область каждой ссылки не меньше 44px, а карточки остаются удобными при ширине экрана 375px.
- Изменения относятся только к карточкам раздела «Топ-20 фильмов».

## Готово, когда

- У каждой из 20 карточек видны две разные ссылки с требуемыми подписями.
- Ссылка на трейлер содержит название и год выбранного фильма и открывает поиск YouTube в новой вкладке.
- Ссылка на полный фильм содержит название и год выбранного фильма и открывает поиск Кинопоиска в новой вкладке.
- Для добавленного в данные ТОП-20 фильма ссылки появляются автоматически и корректно работают с кириллицей и специальными символами.
- Внешний переход выполняется только по нажатию, без фоновых интернет-запросов приложения.
- При ширине 375px подписи не обрезаны, ссылки доступны для нажатия, карточки и горизонтальная прокрутка работают как раньше.
- Остальные коллекции, данные `localStorage`, рейтинги и существующая функциональность не изменились.
