# Добавление фильма или сериала

## Для кого и зачем

Функция предназначена для пользователя, который ведёт личный список фильмов и сериалов. Она позволяет добавить новую запись, чтобы не забыть интересующий контент, отслеживать его просмотр и хранить основную информацию в одном месте.

## Что должно быть

- Пользователь может открыть форму добавления новой записи.
- Пользователь выбирает тип записи: «Фильм» или «Сериал».
- Пользователь указывает название. Это обязательное поле.
- Пользователь может указать год выпуска, жанр, описание и ссылку на постер.
- Пользователь выбирает статус просмотра:
  - «Хочу посмотреть»;
  - «Смотрю»;
  - «Просмотрено».
- Если статус не выбран, по умолчанию устанавливается «Хочу посмотреть».
- После сохранения запись появляется в общем списке.
- В карточке отображаются как минимум название, тип записи и статус просмотра.
- Пользователь получает понятное сообщение, если запись не удалось сохранить или обязательные данные заполнены неверно.
- Пользователь может отменить добавление без сохранения записи.

## Примеры

Пользователь открывает форму и вводит:

- тип: «Фильм»;
- название: «Дюна»;
- год выпуска: 2021;
- жанр: «Фантастика»;
- статус: «Хочу посмотреть».

После сохранения в списке появляется карточка фильма «Дюна» со статусом «Хочу посмотреть».

Готово, когда:

- Фильм успешно добавляется в общий список.
- Название, год выпуска, жанр и тип записи сохраняются корректно.
- В карточке отображается статус «Хочу посмотреть».
- После обновления страницы запись остаётся доступной.

Добавление сериала

Пример:

Пользователь открывает форму и вводит:

- тип: «Сериал»;
- название: «Разделение»;
- год выпуска: 2022;
- статус: «Смотрю».

После сохранения в списке появляется карточка сериала «Разделение» со статусом «Смотрю».

- Готово, когда:
- Сериал успешно добавляется в общий список.
- Тип записи сохраняется как «Сериал».
- Выбранный статус «Смотрю» отображается в карточке.
- Название и год выпуска сохраняются корректно.

Добавление с минимальными данными

Пример:

Пользователь выбирает тип «Фильм», вводит название «Интерстеллар» и сохраняет запись. Она добавляется со статусом «Хочу посмотреть».

- Готово, когда:
- Запись успешно сохраняется без заполнения необязательных полей.
- Обязательные данные позволяют создать запись.
- Статус автоматически устанавливается на «Хочу посмотреть».
-Новая карточка появляется в общем списке.



### Добавление фильма

Пользователь открывает форму и вводит:

- тип: «Фильм»;
- название: «Дюна»;
- год выпуска: 2021;
- жанр: «Фантастика»;
- статус: «Хочу посмотреть».

После сохранения в списке появляется карточка фильма «Дюна» со статусом «Хочу посмотреть».

### Добавление сериала

Пользователь открывает форму и вводит:

- тип: «Сериал»;
- название: «Разделение»;
- год выпуска: 2022;
- статус: «Смотрю».

После сохранения в списке появляется карточка сериала «Разделение» со статусом «Смотрю».

### Добавление с минимальными данными

Пользователь выбирает тип «Фильм», вводит название «Интерстеллар» и сохраняет запись. Она добавляется со статусом «Хочу посмотреть».

### Ошибка заполнения

Пользователь пытается сохранить форму без названия. Запись не создаётся, а рядом с полем названия появляется сообщение о необходимости его заполнить.

## Ограничения

- Название не может состоять только из пробелов.
- Длина названия — не более 200 символов.
- Год выпуска, если указан, должен быть целым числом в допустимом диапазоне от 1888 года до следующего календарного года включительно.
- Описание — не более 2000 символов.
- Ссылка на постер, если указана, должна быть корректным URL с протоколом `http` или `https`.
- Тип записи может иметь только одно из двух значений: «Фильм» или «Сериал».
- Статус просмотра может иметь только одно из трёх значений: «Хочу посмотреть», «Смотрю» или «Просмотрено».
- В рамках этой функции автоматический поиск сведений о фильме или сериале во внешних источниках не предусмотрен.
- Добавление дубликата не блокируется: пользователь может сохранить записи с одинаковым названием.

## Готово, когда

- Форму добавления можно открыть и закрыть без изменения списка.
- Фильм или сериал сохраняется при корректно заполненном обязательном поле «Название».
- Тип записи и выбранный статус сохраняются без изменений.
- При отсутствии выбранного статуса сохраняется статус «Хочу посмотреть».
- Новая запись сразу отображается в общем списке.
- Карточка новой записи показывает название, тип и статус просмотра.
- Некорректные значения не сохраняются, а пользователь видит понятные сообщения об ошибках.
- После обновления страницы добавленная запись остаётся доступной, если приложение поддерживает постоянное хранение данных.
- Основные сценарии добавления фильма, сериала, записи с минимальными данными и ошибки валидации проверены.
