## Git
- Коммит и push выполняй самостоятельно, но только после моей ручной проверки и явного ответа «да».
- Перед началом работы выполни git status. Если есть незакоммиченные изменения — остановись, сообщи о них и спроси, что с ними делать.
- После завершения каждого шага или создания файла требований проведи самостоятельную проверку. Затем остановись и покажи: 1) изменённые файлы (git status --short); 2) краткое описание выполненной работы; 3) что мне необходимо проверить вручную.
- В конце обязательно спроси: «Коммитим?»
- Мой ответ «да» означает разрешение только на коммит и push. Он не разрешает переходить к следующему шагу разработки.
- После моего «да» выполни по очереди: 1) git add . 2) git commit -m "Краткое описание изменений на русском языке" 3) git push
- Если git remote -v не показывает удалённый репозиторий — выполни коммит, пропусти push и сообщи мне об этом.
- Если push требует указать upstream, выполни git push -u origin <текущая ветка>.
- Если push отклонён или требует авторизации — остановись и покажи полный текст ошибки.
- Если любая Git-команда завершилась ошибкой — остановись, покажи ошибку целиком и не пытайся обходить проблему самостоятельно.
- Если я ответил «нет» или описал ошибку — исправь проблему, повтори проверку и снова покажи изменённые файлы. После этого снова спроси: «Коммитим?»
- Без моего явного «да» запрещено выполнять коммит или push.
- Не переписывай историю Git. Запрещены git reset --hard, git push --force и аналогичные опасные операции.

## Большие функции
- Если функцию нельзя реализовать и проверить за один раз, разбей её на 3–6 последовательных шагов.
- В конце соответствующего файла specs/NNN-name.md добавь раздел ## Шаги.
- Каждый шаг должен содержать: чекбокс [ ]; 1) краткое описание того, что будет реализовано; 2) описание того, что появится на экране; 3) проверку результата вручную за 2–3 действия.
- Первым ставь базовый шаг, от которого зависят остальные.
- Реализуй только один шаг за раз. Не переходи к следующему без моей проверки и отдельного подтверждения.
- После завершения шага отметь его [x] в разделе Шаги.
- После этого действуй по разделу Git: покажи изменения, опиши ручную проверку и спроси «Коммитим?»
- Только после моего «да» выполняй коммит и push.
- Не создавай новые файлы тестов. Проверяй функциональность вручную и самостоятельно проверяй отсутствие ошибок.
- Не переходи к следующему шагу автоматически после коммита. Дождись моего отдельного указания.
